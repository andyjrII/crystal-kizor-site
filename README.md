# Crystal Kizor: landing page
Next.js (App Router) + TypeScript. Statically rendered, no client JS beyond the framework.

    npm install
    npm run dev      # http://localhost:3000
    npm run build

Copy and links live in `lib/brands.ts`. Replace every `href: '#'` and the placeholder `contactEmail` before launch.
Deploy: push to GitHub, import the repo on Vercel.
